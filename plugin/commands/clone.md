---
description: Download a project from Prototyper to work on it
argument-hint: "<project name>"
---

Get the code of a Prototyper project following the prototyper skill: find it with `list_projects` if needed, then call `clone_project`. Afterwards install the dependencies and build with the project's own commands to check it works, and tell the user the folder, the client link and whether the client left a review to apply.

Project: $ARGUMENTS
